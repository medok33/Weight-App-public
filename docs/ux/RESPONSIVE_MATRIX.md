| Widths | Navigation / layout | CTA, image, sheet, overflow |
|---|---|---|
| 360, 375, 390, 430 | Mobile top bar + five tabs; single column and safe-area bottom clearance | CTA in first flow; image above or omitted, never splits copy; bottom sheets; wrap long RU text |
| 768, 834 | Compact rail; constrained two-column only when content fits | CTA stays with decision; dialog/sheet adapts; no horizontal page overflow |
| 1024 | Compact-to-permanent sidebar transition; editorial canvas | Two columns allowed; dialogs centered |
| 1280, 1440, 1728 | Persistent sidebar, max 1320px content | Metrics secondary; media contained; no separate desktop IA |

Typography may reduce hierarchy before truncating meaning. Sticky navigation never covers final interactive content.
