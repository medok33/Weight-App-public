# Navigation model

Desktop uses a persistent primary navigation: Today, Plan, Tracking, Progress,
and Settings. Mobile uses the same information architecture with a bottom tab
bar for Today, Tracking, Progress, and Settings; Plan is reached from Today.

Global actions include account menu, help, privacy/consent settings, and safety
exit. Navigation preserves loading, empty, error, forbidden, and success states.
Deep links return to the requested route after authentication, unless a safety
gate must run first.
