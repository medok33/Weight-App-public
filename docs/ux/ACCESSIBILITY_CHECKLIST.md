# Accessibility checklist

- Keyboard order and visible focus are correct.
- Every input has a label, error, and autocomplete hint.
- Contrast meets WCAG AA; color is never the only signal.
- Dialogs trap focus and return it to the trigger.
- Screen-reader names, landmarks, headings, and live errors are present.
- Motion respects reduced-motion preferences; touch targets are at least 44px.
