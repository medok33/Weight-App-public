# Weight App

Weight App is a modular web application for personal nutrition, activity, and workout planning.

This repository is a sanitized public code snapshot. It contains application source, database migrations, tests, and public CI configuration. Private project governance, historical repository history, deployment infrastructure, environments, and operational records are intentionally excluded.

## Development

Install dependencies with pnpm, then use the workspace scripts listed in `package.json`. Disposable local services and CI configuration are documented in the included compose and workflow files. Use `.env.example` as the placeholder-only configuration reference.

## Scope

This repository is for application code, migrations, tests, and build/test CI. Production deployment and private operational configuration are out of scope.
